## Abstract

RGB-D salient object detection (SOD) has gained significant attention due to the complementary information provided by depth maps. However, existing methods primarily rely on visual cues (RGB and depth) and often fail to leverage high-level semantic guidance, leading to suboptimal performance in complex scenes. In this paper, we propose a novel text answer guided network (TAGNet) that integrates text answer descriptions generated by vision language model (VLM) as semantic priors to enhance RGB-D SOD. Specifically, TAGNet introduces three key innovations: 1) a text branch using VLM to generate concise descriptions of salient object and a text encoder to extract structured semantic prior; 2) a visual encoder that processes RGB (appearance details) and Depth (spatial cues) input to produce multi-scale visual features; 3) a cross-modal fusion decoder (CMFD) adopts hierarchical integration to progressively fuse semantic-text features with multi-scale visual cues. The core of CMFD include modal enhanced fusion (MEF) emphasizing RGB-D complementary information, and visual-text fusion (VTF) for precise semantic-visual alignment. Extensive experiments on five public datasets confirm TAGNet’s superiority over the cutting-edge methods. Ablation studies validate the efficacy of text answer guidance, and synergistic multi-modal fusion, offering a novel paradigm for RGB-D SOD. Code can be accessed at: https://github.com/ Voruarn/TAGNet.
